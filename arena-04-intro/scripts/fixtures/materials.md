# PathFuse：统计残差与图信号融合的时序异常检测（底稿方法摘要，自测夹具）

## 1. 背景与问题
工业传感器流数据上的异常检测需要在低误报与低算力之间取得平衡。目标部署环境训练样本少、标注稀缺，且只有 CPU 资源。

## 2. 记号与数据
设通道数为 C、窗口长度为 W。使用三个公开数据集（SKAB、WADI 子集、SWaT 子集）。

## 3. 方法
PathFuse 由三个模块组成：
- 残差分支：对每个通道做季节性分解后拟合自回归残差，输出统计分数；
- 图信号分支：以传感器拓扑为先验做轻量图滤波，输出结构分数；
- 融合判别器：将两路分数经温度校准后加权融合。
