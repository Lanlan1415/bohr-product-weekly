# 要素齐全性清单与评分锚点（文献翻译）

用途：步骤 6 组装后、步骤 7 自查前，逐条勾选。每条对应题面评分维度，可机器或人工核验。
记号：`[ ]` 未达成 / `[x]` 已达成 / `[N/A]` 材料本身没有该元素（须在 evidence_map 登记"原文未报告"）。

## A. 实际效果（40 分）

### A1 任务完成度（15 分）
- [ ] `/app/output/bilingual_translation.md` 存在：是段号对齐的双语对照稿，不是大意概述或改写。
- [ ] result.json 顶层包含 case.json 的 output_contract 声明的**每一个**字段（字段名逐字一致）。
- [ ] 任务指定的翻译区间（全文或指定段落）全部覆盖；区间外内容未混入。
- [ ] 交付含可复用的术语表文件（glossary.tsv）。

### A2 结果正确性（15 分）
- [ ] term_consistency.py 已运行且输出留存：无禁用变体、无"原文出现但译名缺失"（修一轮后仍有 FAIL 的记入 uncertainty，不阻塞交付）。
- [ ] 抽查 ≥5 处数字与单位（10 mM、60 °C、3.37 eV）与原文完全一致，未做未授权的换算。
- [ ] 抽查 ≥2 处公式编号、≥3 处图表编号、≥3 处文献引用编号（[12]、Fig. 3、Eq. (2)）与原文一致。
- [ ] 否定与限定关系抽查：no/not/never/only/except/unless/at most/at least/if…then 逐处核对无翻转。
- [ ] 指代关系抽查：it/this/these/其/该 的指代对象与原文一致。

### A3 结果完整性（5 分）
- [ ] 全文段落（含摘要、结论）段号连续无缺；图表题注与表头已译且编号不动。
- [ ] 公式按编号保留原式，编号未漂移；文献引用标记 [n] 保留。
- [ ] 术语表条目覆盖：标题、摘要、正文、图注、结论五处均用到的术语全部在表中。
- [ ] OCR/残缺/图片型元素都有 `[UNSURE]` 或 `[NOT_TRANSLATED]` 标注。

### A4 结果可核验性（5 分）
- [ ] 每段译文可通过 `[P###]` 指回原文同号段落，段号→页码映射在 evidence_map 中。
- [ ] （v2）每句译文可通过 `[P###-S##]` 句级锚号指回原句与页码；sentence_anchor.py 审计已运行且报告留存（FAIL 项已修一轮或记入 uncertainty，不阻塞交付）。
- [ ] 每个术语的译名决策（首选/禁用变体）在术语表中留痕。
- [ ] 所有 `[UNSURE]` 处列出原文、候选译法与需确认事项；无法判断的内容没有被写成事实。

## B. 使用增益（25 分）
- [ ] 术语表是独立文件且被脚本强制执行——基础 Agent 通常只在提示里"声明"术语。
- [ ] 段号对齐可由 align_check.py 机器验证——基础 Agent 无法证明无漏段。
- [ ] 两份机器核验报告留存 /app/work/（增益可验证）；（v2）句级锚定审计报告同步留存。
- [ ] 术语表、分段规则可直接复用于同学科下一篇文献（效率增益）。

## C. 创新增益（15 分）
- [ ] 术语"抽取→锁定→脚本强制→全篇回填"闭环完整运行过（非纸面规则）。
- [ ] 跨页/跨栏断句续接在 source_paras.md 有留痕（续接标记）。
- [ ] 译文核验清单逐项勾选留痕，而非"通读一遍觉得顺"。
- [ ] （v2）句级锚定 + 来源清点/对齐审计实际运行（anchor_report.md 留存）——基础 Agent 通常无法证明"每句都回链原句、零漏句"。
- [ ] （v2）修订模式下变更表"改前→改后+依据"齐全，修订边界可机器复核。
- [ ] （v2）finalize.py 交付固化：任何中断点都能交出诚实部分 + skipped_reason。

## D. 可靠体验（10 分）
- [ ] 调用说明（SKILL.md §3）可直接照抄执行；不依赖 CWD、不依赖网络。
- [ ] 扫描件/图片公式/参考文献无法解析/原文残缺/语言混杂五类异常各有处置规则。
- [ ] 预算耗尽时的降级形态明确（已译段保持对照 + 未译段显式标注 + partial）。
- [ ] （v2）result.json 写入前经过 contract_check.py 前置校验（输出留存）。
- [ ] （v2）selftest.py 负路径用例通过：漏段/禁用变体/零锚句译稿确实以退出码 1 拒绝，合格译稿不被新检查误判 FAIL（WARN 纪律）。
