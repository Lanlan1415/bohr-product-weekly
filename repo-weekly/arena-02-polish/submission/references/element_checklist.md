# 要素齐全性清单与评分锚点（写作02｜学术语言润色）

交付前逐项打勾。每条标注其支撑的评分点（实际效果 40 / 使用增益 25 / 创新增益 15 / 可靠体验 10 / 生态贡献 10）。

## A. 契约与交付结构（实际效果·任务完成度）

- [ ] 已读 `/input/case.json`，`result.json` 含 `case_id`，`output_contract` 全部原始字段逐字透传；
- [ ] 交付 = **润色后完整文本 + 逐句修改说明**，不是写作建议，不是局部片段；
- [ ] `/app/output/` 含：润色稿、`change_log.md`、`evidence_map.md`、`result.json`；
- [ ] `result.json` 含诚实 `status`、`sources`、`uncertainty`、`change_log`。

## B. 改得对（实际效果·结果正确性）

- [ ] L1 级硬错误（主谓一致/时态/冠词/介词/单复数/标点/悬垂修饰）已系统性排查，不是只改显眼的几处；
- [ ] 修改是真修正而非"换一种说法掩盖"（每条的"类型+理由"能说明错在哪）；
- [ ] 长句切分后信息分配不变（没有拆丢条件状语、限定从句）。

## C. 说得像（实际效果·结果正确性；使用增益·质量增益）

- [ ] 语域匹配目标文体：期刊去宣传化、学位论文层次分明、基金突出价值、审稿回复礼貌对点（见 style_guide）；
- [ ] 术语全篇统一：terms.txt 批准写法在全文一致；缩写首次出现 = 全称（缩写）；
- [ ] 中式英语/直译腔已按 style_guide §4 清单清理；
- [ ] 同一段落重复润色未造成结论漂移（对照 original_snapshot）。

## D. 没改坏（实际效果·结果正确性；创新增益·新增能力）

- [ ] `conservation_check.py` 退出码 0：数字/术语/引用标记/图表编号/公式全部守恒；
- [ ] 限定词强度未变化（may→prove、suggest→demonstrate、可能→必然 等一律禁止）；
- [ ] 因果与相关未被混淆（correlate→cause、表明→导致 类升级禁止）；
- [ ] 否定范围、条件句、量词保持原样；
- [ ] 有意为之的守恒例外（如期刊要求单位换算）在 change_log 逐条注明依据。

## E. 讲得清（实际效果·结果可核验性；生态贡献）

- [ ] 每条修改记录含：编号、级别（L1-L4）、原文句、改后句、类型、理由六要素；
- [ ] 【备选】条目给出 ≥2 个候选 + 倾向 + 理由，未硬改；
- [ ] 修改记录可逐条回溯到润色稿位置（章节/段落标注）；
- [ ] evidence_map 把数字、术语、引用、图表和关键论断映射到来源 [S#]。

## F. 完整性（实际效果·结果完整性）

- [ ] 指定章节逐段处理，无漏段（章节清单与来稿逐一对照）；
- [ ] 术语表建全（概念、缩写、大小写与连字符规则）；
- [ ] 中英双语任务：双语对照与修改清单齐全；
- [ ] 待确认项集中列出，未确认的文本明确标注。

## G. 可靠与异常（可靠体验 10）

- [ ] 触发边界遵守：纯问答不擅自改写；
- [ ] 超长/编码混乱/公式引用混杂/中英混排/术语表冲突/文体不明，六种情形各有处置记录；
- [ ] 脚本失败时已手工执行同等检查并在 change_log 说明；
- [ ] finalize 在任何中间态都导出了诚实部分（verify 缺失 → 原文 + skipped_reason）；
- [ ] audit 通过：无事后篡改、守恒复核过、回退编辑已在 change_log 留痕；
- [ ] result.json 写入前做过契约前置校验（finalize 自动执行，缺失字段置 null + uncertainty）。

## H. 生态贡献（生态贡献 10）

- [ ] 术语表、风格规则可被他人直接复用到自己稿件；
- [ ] 示例明确标注合成/示意；
- [ ] 文档说明适用范围、限制与维护信息；
- [ ] 验证与限制声明在 SKILL.md 与 examples 可见：本地仅合成验证，未声称平台分数。

## I. v2 流水线专项（锚定与回退）

- [ ] 编辑记录全部先抄原句再写改文（锚定协议）；id-only 记录有 WARN 认知与理由；
- [ ] verify 回退清单逐条处置（修正重投 / 有意例外+依据 / 放弃），无静默绕过；
