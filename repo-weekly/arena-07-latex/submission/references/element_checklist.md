# 要素齐全性清单与评分锚点（写作13｜LaTeX 写作与编译）

交付前逐项打勾。每条标注其支撑题面的哪个评分点（实际效果 40 / 使用增益 25 / 创新增益 15 / 可靠体验 10 / 生态贡献 10）。

## A. 契约与交付结构（实际效果·任务完成度）

- [ ] 已读 `/input/case.json`，`result.json` 含 `case_id`，且 `output_contract` 声明的**全部原始字段**逐字透传（字段名一字不差）；
- [ ] `/app/output/` 含：可编译的 .tex 工程（主文件+章节+图+.bib+模板文件）、真实编译的 PDF、`build_record.md`、`evidence_map.md`、`result.json`；
- [ ] `result.json` 含 `status`、`sources`、`uncertainty`、`change_log`，status 与编译实情一致；
- [ ] 曾尽早落盘过一版可编译的最小骨架（change_log 可见迭代记录）。

## B. 编译得通（实际效果·结果正确性；使用增益·质量增益）

- [ ] 编译链正确：含参考文献时 pdflatex→bibtex/biber→pdflatex×2，或 latexmk -pdf；
- [ ] 编译到收敛：最终日志无 "Rerun to get cross-references right"、无 undefined references/citations；
- [ ] `log_triage.py` 对最终日志退出码 0；曾经的错误每条有 文件:行号+根因+修复 记录；
- [ ] `tex_static_check.py` 在每次大改后重跑且退出码 0；
- [ ] PDF 为本次真实编译产物（build_record 有命令与时间，PDF 时间戳不早于最终 .tex）。

## C. 改得对（实际效果·结果正确性）

- [ ] 任务改动点逐项落实，每项在 evidence_map.md 可回溯到源码位置；
- [ ] 公式符号与编号与正文叙述一致，\eqref/\ref 无悬空；
- [ ] 表格数值与材料一致，列宽/跨页/合并单元格按规范处理，未靠 \resizebox 缩放掩盖溢出；
- [ ] \cite 全部命中 .bib 条目，参考文献样式与排序符合模板；
- [ ] 事实与数值只来自给定材料，未新增材料外内容。

## D. 模板合规（实际效果·结果完整性；可靠体验·运行稳定性）

- [ ] 题目给定的 .cls/.sty 逐字节未改（可与 /input 原件比对）；
- [ ] 模板必填项（题名/作者/单位/摘要/关键词等，以模板文档为准）逐项填写或显式标注待确认；
- [ ] 新增宏包与模板已加载宏包无冲突（加载顺序检查过，change_log 说明新增理由）；
- [ ] 未通过 \renewcommand 重定义模板内部命令来改变版式。

## E. 交得可用（实际效果·结果完整性）

- [ ] 交付的是结构清楚的源码工程（主文件/章节/图表/参考文献分层），不是单个巨型 .tex 或片段；
- [ ] 源码可继续编辑：改动处有注释、无大面积注释掉的死代码；
- [ ] 没有把 PDF、截图或无法编译的片段当作"源码"交付；
- [ ] 图文件格式与编译链兼容（pdflatex 用 PDF/PNG/JPG，不用 EPS 除非有 epstopdf）。

## F. 复现得了（实际效果·结果可核验性）

- [ ] build_record.md 写明：TeX 发行版与版本、编译命令序列、轮次、非标准宏包/字体依赖；
- [ ] 工程自包含：他人拿到 /app/output 的工程 + 记录的命令即可重建 PDF；
- [ ] 相对路径引用（\input/\includegraphics 不带绝对路径、不带 ..）；
- [ ] 编译失败情形：完整 .log 已保留，PDF_FAILED.md 说明卡点，status=partial/failed。

## G. 可靠与异常（可靠体验 10）

- [ ] 缺宏包、缺字体、报错级联、模板缺失、权限不足五种情形各有处置预案与记录；
- [ ] 脚本失败时已手工执行同等检查并在 change_log 说明；
- [ ] 重复运行产物一致（无时间戳/随机内容进 PDF 元数据之外的正文）。

## H. 生态贡献（生态贡献 10）

- [ ] error_fix_table.md、工程结构模板、编译记录模板可脱离本案例复用；
- [ ] 文档与示例齐全，示例明确标注合成/示意；
- [ ] 失败模式与修复经验沉淀完整，对他人有参考价值。
