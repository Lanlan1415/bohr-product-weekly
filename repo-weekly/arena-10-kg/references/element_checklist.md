# 要素齐全性清单与评分锚点（阅读15｜文献知识图谱构建）

交付前逐项打勾。每条标注其支撑题面的哪个评分点（实际效果 40 / 使用增益 25 / 创新增益 15 / 可靠体验 10 / 生态贡献 10）。

## A. 契约与交付结构（实际效果·任务完成度）

- [ ] 已读 `/input/case.json`，`result.json` 含 `case_id`，且 `output_contract` 声明的**全部原始字段**逐字透传（字段名一字不差）；
- [ ] `/app/output/` 含：`graph_nodes.csv`、`graph_edges.csv`、`graph_summary.md`、`evidence_map.md`、`result.json`；
- [ ] `result.json` 含 `status`（success/partial/failed 且与实情一致）、`sources`、`uncertainty`、`change_log`；
- [ ] 曾尽早落盘过一版诚实的小图（change_log 可见迭代记录，而非最后一刻一次性输出）。

## B. 抽得准（实际效果·结果正确性）

- [ ] 每个实体都能指出其在论文中出现的段落（paragraph_id）；
- [ ] 无"凭领域常识补全"的实体（如论文没提的方法、指标）；
- [ ] 实体类型覆盖任务要求的类别：材料/方法/任务/指标/结论/研究者（以 case.json 要求为准，未要求的可缺）；
- [ ] 数值型结论（电导率、效率、温度等）连同**数值、单位、测试条件**一起挂在边上或节点属性里，不是孤立的数。

## C. 连得对（实际效果·结果正确性）

- [ ] 每条边的关系类型在 `references/predicates.txt` 清单内；
- [ ] 关系**方向**与原文一致（A 优于 B ≠ B 优于 A；X 制备 Y ≠ Y 制备 X）；
- [ ] 共现、综述转述、作者推测没有被标成"直接实验证据"；证据强度如实标注；
- [ ] 适用条件（温度、压力、组成范围）随边保留，没有把条件性结论写成无条件结论；
- [ ] 比较-条件门：outperforms/more_stable_than/compares 边全部带 condition，graph_check.py 通过。

## D. 对得齐（实际效果·结果正确性；创新增益·新增能力）

- [ ] 缩写/全称/大小写/中英文/全半角已按归并规则统一；
- [ ] 缩写候选表（abbrev_candidates.csv）随阅读同步登记，graph_check --abbrevs 核对全部落点、无冲突；
- [ ] `graph_check.py` 退出码 0：无重复实体、无别名冲突；
- [ ] 每一次合并都在 `evidence_map.md`/对齐名册有依据（出自哪篇哪段的哪种写法）；
- [ ] 实例级实体（样品/模型/数据集/实验/条件）合并均有共享标识符；
- [ ] 每一处"不得合并"（不同样品/模型实例/数据集/条件）都有书面理由；
- [ ] 没有把不同论文的条件、样本、数值结果合成一个结论。

## E. 回得去（实际效果·结果可核验性）

- [ ] 每条边：source_id + paragraph_id + 原文短引（≤40 字逐字）三字段非空（脚本强制）；
- [ ] 位置使用组织方 JATS 段落 ID；**没有**把自建页码标成原 PDF 页码；
- [ ] 每个节点的所有出现位置可回查（至少在 extraction 工作稿中列出）；
- [ ] 未报告项、源内冲突在摘要中明确保留，没有被悄悄抹平。

## F. 查得到（实际效果·结果完整性；使用增益·质量增益）

- [ ] ≥3 个**实际执行过**的查询，每个含：查询语句、结果子图（涉及的节点与边）、支撑证据原文、无法确定项；
- [ ] 查询类型不单一：至少覆盖"按实体查""按关系查""跨篇比较或冲突查询"中的两类；
- [ ] 查询结果全部来自图内数据（有向可达），不是重新读论文临时回答，不推断图外科学事实；
- [ ] GraphML 已导出且 graphml_roundtrip.py 回导一致性验证通过（退出码 0）；
- [ ] result.json 写盘前过了 contract_check.py 契约前置校验。

## G. 可靠与异常（可靠体验 10）

- [ ] 材料缺失/PDF 读不出/实体同名/证据冲突/查询无结果，五种情形各有处置记录；
- [ ] 脚本失败时已手工执行同等检查并在 change_log 说明；
- [ ] 重复运行不会产生不同 node_id 分配（ID 规则确定，见 style_guide）。

## H. 生态贡献（生态贡献 10）

- [ ] schema（实体/关系/属性）定义完整、可被他人复用；
- [ ] 文档与示例齐全，示例明确标注合成/示意；
- [ ] 查询模板可复用（summary 中的查询写法对他人有参考价值）；
- [ ] 验证与限制声明在 SKILL.md 与 examples 可见：本地仅合成验证，未声称平台分数。
