# 要素齐全性清单与评分锚点（阅读10）

用法：交付前逐条勾选。每条都可操作、可核验；"锚点"指 `[S# p.页 §节 ¶段]` 或
`[S# fig.号]`/`[S# 表号]` 格式（见 method_rules.md §3）。

## A. 对得上（结构对齐）

- [ ] A1 笔记的章节摘要区按论文**实际章节标题与顺序**组织（不是"背景-方法-结果"通模板）。
- [ ] A2 section_map.md 中列出的论文每一章，在笔记中都有对应条目或被显式说明"略读/与本任务无关"。
- [ ] A3 相邻章节之间的承接关系（如"第3节的方法服务于第2节提出的假设"）至少有 1 处显式记录。
- [ ] A4 三级摘要齐全：一句话 ≤60 字、一段 ≤250 字、详细版含问题-方法-结果-局限四要素。

## B. 留得住（要素保留）

- [ ] B1 研究问题：主问题 + 子问题/假设分列，带锚点。
- [ ] B2 数据与材料：数据集/样本来源、规模、时间范围、获取方式，逐项列出或标"未报告"。
- [ ] B3 方法与条件：方法名称之外，**让结论成立的前提条件**（实验装置、参数、阈值、
      统计检验、适用假设）单独成行。
- [ ] B4 主要结果：数值结果带单位与不确定度（若原文给出），每条带锚点。
- [ ] B5 局限与适用边界：区分"作者自述局限"与"读者发现的潜在局限"，分别标注。
- [ ] B6 未报告与不确定项：显式一节；写"未报告"而非留空或编造。
- [ ] B7 可复用要素：代码/数据链接、量表、实验参数表、可借用图表、可引用定义，单独成节。

## C. 找得回（证据回链）

- [ ] C1 论断→证据映射表每条论断都有：原文引文（≤30 字）+ 锚点 + 证据类型 + 核验状态。
- [ ] C2 锚点编号 S# 全部出现在 materials_register.md 登记表中（notes_check.py 检查 2）。
- [ ] C3 所有锚点含定位信息（页/节/段/图表至少其一），无"只写 [S1]"的笼统出处。
- [ ] C4 关键数值（含单位/%/p 值）所在行带锚点（notes_check.py 检查 5 无 WARN）。
- [ ] C5 图/表引用精确到编号（fig.2 / 表1），不写"见文中附图"。

## D. 用得上（可复用性）

- [ ] D1 知识点条目化：概念/变量/方法/结论分条，每条带锚点，术语给"中文（英文, 缩写）"。
- [ ] D2 同义表述归并：同一概念的多种说法合并为一条并注明别名，无重复条目。
- [ ] D3 多篇案例已产出 comparison_matrix.md，矩阵每格带锚点，分歧/互补单独成节。
- [ ] D4 字段字典与模板一致（templates/note_skeleton.md），他人可照模板继续加工。

## E. 契约与诚实（result.json）

- [ ] E1 result.json 含 case_id，且与 case.json 一致。
- [ ] E2 output_contract 声明的全部原始字段都在 result.json 中，字段名未改写。
- [ ] E3 status 诚实：有缺口即 partial，uncertainty 说明缺口与人工接管位置。
- [ ] E4 sources 列出实际使用的 S 编号；change_log 记录每轮改动（含脚本降级）。
