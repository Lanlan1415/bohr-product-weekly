# 基础 Agent 典型失败模式与对策（阅读10）

以基础 Agent（不加载本 Skill）在真实论文阅读任务上的高频失败为依据，
每条给出本 Skill 的对策及其落点文件。

## F1 通篇摘要冒充结构化笔记

**现象**：输出一段连贯的"读后感"，无字段、无章节对齐、无锚点；评测者无法
逐条核验，"对得上/找得回"两项直接丢分。
**对策**：强制骨架（templates/note_skeleton.md）+ 第 2 步先生成 section_map.md
再写笔记；notes_check.py 检查 1 缺字段即 FAIL。

## F2 章节顺序凭印象重排

**现象**：按"背景-方法-结果-结论"通模板组织，遇到综述、短文、通信类论文
（无 IMRaD 结构）时骨架与原文完全错位。
**对策**：章节对齐判定（method_rules.md §1）要求笔记一级条目与论文实际标题
一一对应；不合格视为方法错误而非风格问题。

## F3 结论有、证据无

**现象**："本文提出了一种高效方法，效果显著"——没有数值、没有页码、没有图表号，
评测"结果可核验性"失分。
**对策**：论断→证据映射表为必备交付（evidence_map.md），每条论断强制
"引文+锚点+证据类型"；notes_check.py 检查 3 逐行卡锚点。

## F4 未报告内容被脑补或留白

**现象**：原文没给样本量，基础 Agent 要么编一个合理数字，要么字段留空；
前者构成编造科学数据，后者被判要素缺失。
**对策**：三级标注体系（method_rules.md §5）+ 笔记末节"未报告与不确定项"强制
显式填写（notes_check.py 检查 4）。

## F5 方法条件丢失导致结论失真

**现象**：只记"模型准确率 94%"，丢了"在 XX 数据集、5 折交叉验证、
类别均衡采样"这些让结论成立的前提；他人复用笔记时被误导。
**对策**："方法与条件"字段把前提条件单独成行（method_rules.md §2 表），
自查清单 B3 专门勾选。

## F6 图表与双栏解析错位

**现象**：双栏 PDF 文本错序、图表说明与正文拼在一起，基础 Agent 把图注
当正文结论，或张冠李戴引用错页码。
**对策**：inventory.py 先探测文本层质量；锚点要求精确到 fig.N/表N 并回原文
复核；读不出的图表声明"未能解析"而非编造（SKILL.md §7）。

## F7 知识点条目重复、术语漂移

**现象**：同一概念出现 3 种写法分成 3 条；缩写前后不一致；条目之间互相矛盾。
**对策**：知识点清单归并规则（method_rules.md §7 反模式 7）+ 术语格式
"中文（English, 缩写）"（style_guide.md）。

## F8 多篇对比退化为逐篇罗列

**现象**：多篇案例输出三份独立摘要，没有横向比较，"用得上"不达标。
**对策**：comparison_matrix.md 为多篇案例必交付（SKILL.md 第 5 步），
矩阵后强制"分歧与互补"节。

## F9 result.json 契约字段缺失或改名

**现象**：凭印象写字段名，output_contract 声明的原始字段被改写或漏掉，
评测契约直接不合规。
**对策**：第 0 步抄录契约字段清单；selfcheck.py 用 case.json 实测比对，
缺字段即 FAIL，不依赖记忆。

## F10 先写契约后验证，或阶段失败导致零交付（v2）

**现象**：先把 result.json 写好再回头补笔记，契约字段与真实产物脱节；
或中途某步失败就整案放弃，什么都不交，"可靠体验"归零。
**对策**：契约草稿核对（建议性，不阻塞交付）——摘录与数据核对（notes_check.py）
先于契约落盘，result.json 草稿经 contract_check.py 核对后照常写入 /app/output/
（缺字段补一轮、补不齐记 uncertainty/skipped_reason，method_rules.md §3.2）；
交付韧性约定：任何阶段失败仍交付已完成部分，
跳过阶段写入 skipped_reason（SKILL.md §7）。

## F11 锚点只有页码，重排即失效；章节只覆盖一半（v2）

**现象**：所有出处只写"p.3"，PDF 重排或换版本后全部失效；或章节摘要只写
前几节，后半论文悄悄失踪。
**对策**：稳定原文定位符优先（章节号/图表号）+"页+章节+行区间"复合定位
（method_rules.md §3.1）；chapter-complete 要求逐章覆盖、从略须显式说明，
notes_check.py 检查 6（--section-map 逐节比对）与检查 7（复合定位比例）
以 WARN 级提示。
