# 文体与格式规范（阅读10：结构化笔记）

## 语言

- 笔记正文用简体中文；术语首次出现写"中文（English, 缩写）"，之后用中文或缩写。
- 原文引文保留原文语言（英文引文不翻译），外加 ≤30 字限制，超长截断加"…"。
- 不用评价性词汇（"非常""重大突破""显然"），只陈述原文说了什么。

## 结构

- 文件骨架固定（见 templates/note_skeleton.md）：元信息 → 三级摘要 → 字段区 →
  章节摘要 → 知识点清单 → 可复用要素 → 未报告与不确定项 → 论断→证据映射。
- 标题层级从 `#` 开始逐层递进，不跳级；章节摘要区用论文原章节名作标题并附编号。
- 列表用 `-`；编号列表只用于有顺序含义的内容（步骤、排名）。

## 锚点与标记

- 锚点内嵌在行尾：`……达到 94.2% 的准确率 [S1 p.6 §4.2 表3]`。
- 同一条目多个来源用连续锚点：`[S1 p.3 §2] [S2 p.5 §3.1]`。
- 未报告/无法判断/材料冲突用全角括号内联标注，集中清单放末节。

## 数值与单位

- 数值、单位、有效位数照抄原文，不换算、不四舍五入；确需换算时两者并列并注明换算。
- 百分数、置信区间、p 值保留原文写法（"95% CI [1.2, 2.8]""p < 0.01"）。

## 表格

- 论断→证据映射、对比矩阵用 Markdown 表格；表头与分隔行齐全，单元格内不用换行。
- 表格单元格内容 ≤40 字；写不下的细节放表下注释并给锚点。

## 文件与命名

- 交付文件名固定：`notes.md`、`evidence_map.md`、`comparison_matrix.md`（多篇时）、
  `result.json`；工作文件名固定：`materials_register.md`、`section_map.md`、
  `contract_notes.md`。
- 路径一律正斜杠；引用技能内文件用 `/skills/weekly-skill/` 前缀的绝对路径。
