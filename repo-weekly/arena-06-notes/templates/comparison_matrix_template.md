# 多篇文献横向对比矩阵模板（comparison_matrix.md）

> 用法：案例含两篇及以上文献时，复制为 `/app/output/comparison_matrix.md`。
> 行是要素、列是文献；每格 ≤40 字结论 + 锚点；未涉及写"未报告"。

```markdown
# 文献横向对比矩阵：【案例标题】

- 案例 ID：【case_id】
- 对比文献：S1《【标题】》、S2《【标题】》、S3《【标题】》

## 对比矩阵
| 要素 | S1 | S2 | S3 |
|---|---|---|---|
| 研究问题 | 【……】 [S1 p.1 §1] | 【……】 [S2 p.1 §1] | 【……】 [S3 p.2 §1] |
| 数据与样本 | 【……】 [S1 p.3 §2] | 未报告 | 【……】 [S3 p.3 §2.1] |
| 方法与条件 | 【……】 [S1 §3] | 【……】 [S2 §2.2] | 【……】 [S3 §3] |
| 评价指标 | 【……】 [S1 §4.1] | 【……】 [S2 §3.1] | 未报告 |
| 主要结果 | 【数值+单位】 [S1 p.6 表2] | 【……】 [S2 p.5 fig.3] | 【……】 [S3 p.7 表1] |
| 局限 | 【……】 [S1 §6] | 【……】 [S2 §5] | 【……】 [S3 §6] |

## 分歧与互补
- 分歧1【要素名】：S1 认为【……】[S1 p.x §y]；S2 报告【……】[S2 p.x §y]。
  条件差异：【数据/方法/指标差异能否解释分歧，一句；不能解释则写"分歧原因无法判断"】
- 互补1：S1 提供【……】，S2 提供【……】，合并可得【……】。

## 可比性声明
- 【三篇是否在相同任务/指标/数据上可比；不可比处显式列出，不强行并排】
```
