# 要素齐全性清单与评分锚点（文献文档解析）

用途：步骤 6 组装后、步骤 7 自查前，逐条勾选。每条对应题面评分维度，可机器或人工核验。
记号：`[ ]` 未达成 / `[x]` 已达成 / `[N/A]` 材料本身没有该元素（须在 evidence_map 登记"原文未报告"）。

## A. 实际效果（40 分）

### A1 任务完成度（15 分）
- [ ] `/app/output/parsed_document.md` 存在且非空，不是"看起来像全文的连续文本"，而是分区块、带标记的结构化结果。
- [ ] result.json 顶层包含 case.json 的 output_contract 声明的**每一个**字段（字段名逐字一致，未臆造新字段）。
- [ ] 正文每个段落块都带 `[p.N]` 物理页码与栏标记 `[col.L/R|full]`。
- [ ] 任务要求的每个解析动作（提取/结构化/问答依据）在产物中有对应章节；任务没要求的没有编造。

### A2 结果正确性（15 分）
- [ ] 随机抽查 ≥5 处正文与原文逐字一致（大小写、标点、上下标、希腊字母 α/β/γ 不变形）。
- [ ] 双栏/多栏案例：抽查 ≥3 处栏边界，左栏末句与右栏首句未被拼成一句；跨栏通栏元素（标题、大图）未切进栏文本。
- [ ] 表格抽查：≥1 张表的行列表头与单元格归属正确，跨行跨列有标注；图片型表格标 `[NOT_READABLE: 图片型表格]` 而非编造数字。
- [ ] 公式抽查：≥2 条编号公式，编号与原文一致，符号失真处已标 conf:low 并注明。

### A3 结果完整性（5 分）
- [ ] 元数据六项：标题、作者、单位、摘要、关键词、期刊/年份信息（缺项标"未报告"）。
- [ ] 章节树含层级与编号，每节有起始页码；与正文锚点互查一致。
- [ ] 图表题注逐字提取，含图注中的子图标记 (a)(b)(c)。
- [ ] 参考文献按编号逐条切分，不断行错并；脚注单独成节。
- [ ] 页眉/页脚/页码的处置方式有专门说明（剔除规则 + 剔除内容样例）。

### A4 结果可核验性（5 分）
- [ ] 每个区块标 `[S#]`（材料编号）+ `[p.N]`（页码）+ `[B#]`（区块号）+ `[conf:...]`。
- [ ] 未报告项、材料内部冲突项、无法判断项分别单列，没有写成事实。
- [ ] evidence_map.md 能从任一产出区块反查到来源文件与页码。
- [ ] （v2）每个转写区块注明提取视图（layout/raw/OCR）；视图冲突有取舍留痕。
- [ ] （v2）主产物 §1 含 OCR 页覆盖声明：走 OCR 的页逐页列出，与 ocr_coverage.md 一致；无 OCR 页也显式声明。

## B. 使用增益（25 分）
- [ ] 有 survey.json：基础 Agent 通常不做结构清点，这是可对照的新增中间产物。
- [ ] 有逐区块置信度标注（基础 Agent 几乎不做），low 项可直接引导人工复核。
- [ ] selfcheck.py 输出留存于 /app/work/，证明交付经机器校验（增益可验证）。
- [ ] （v2）contract_check.py / finalize.py 输出留存，证明契约前置校验与交付韧性机制实际运行过。
- [ ] 脚本替代了手工清点/章节定位（效率增益），重跑同案例结果一致（稳定性）。

## C. 创新增益（15 分）
- [ ] 栏序还原有明确规则（整栏读完再换栏）与抽查记录，非默认输出照抄。
- [ ] 异常分级（blocker/major/minor）写入 survey.json，扫描件/加密有独立处置路线。
- [ ] 图表-正文引用回链表（题注 ↔ 首次引用段落）——基础 Agent 通常只做单向罗列。
- [ ] （v2）OCR 页覆盖清单（ocr_coverage.md）+ 表格区域几何登记（table_registry.md）——基础 Agent 通常不做页级覆盖声明与几何先验。
- [ ] （v2）finalize.py 交付固化：任何中断点都能交出诚实部分 + skipped_reason，而非整案失败。

## D. 可靠体验（10 分）
- [ ] 调用说明（SKILL.md §3）可直接照抄执行；不依赖 CWD、不依赖网络。
- [ ] 加密/扫描/乱码字体/页码错乱四类异常各有处置记录或声明。
- [ ] 重复运行脚本输出一致（幂等，只读输入）。
- [ ] （v2）result.json 写入前经过 contract_check.py 前置校验（输出留存）。
- [ ] （v2）selftest.py 负路径用例通过：必须被拒绝的草稿确实以退出码 1 拒绝，原本合格的草稿不被新检查误判 FAIL（WARN 纪律）。

## E. 生态贡献（10 分）
- [ ] SKILL.md 写清用途、触发条件、输入输出、异常处理与限制。
- [ ] 脚本 --help 完整，错误信息明确，退出码语义清楚。
- [ ] examples/ 两个示例均标注"合成/示意"，不冒充正式案例结果。
