# 解析输出文体与格式规范（文献文档解析）

## 1. 区块标记语法（全篇统一，逐区块使用）

每个正文/元素区块以一行标记开头，顺序固定：

```
[B017] [p.5] [col.L] [S1] [conf:high] [view:layout]
```

- `[B#]`：区块号，全文从 B001 起连续编号，证据映射以它为主键。
- （v2）`[view:layout|raw|ocr]`：提取视图标记，追加在标记行末——转写来源对复核者可见（method_rules §8）。
- `[p.N]`：PDF **物理页码**（首页为 p.1）；与印刷页码不一致时在 evidence_map 登记差异。
- `[col.L|R|full]`：栏标记；通栏元素用 `full`。
- `[S#]`：来源材料编号，对应 materials_register.md 中的 S1..Sn。
- `[conf:high|medium|low]`：解析置信度；medium/low 必须在块末附 `置信度依据：…` 一行。
- 读不出的内容：`[NOT_READABLE: 具体原因]`，例如 `[NOT_READABLE: 图片型表格]`、`[NOT_READABLE: 字体映射缺失]`。
- 跨页续接：块尾标 `[cont.→p.N+1]`，下页对应块首标 `[cont.←p.N]`。

## 2. 引用原文的规则

- 所有"原文"内容**逐字摘录**：大小写、标点、斜体记号、上下标字符照原样，不改正原文的拼写错误（必要时加 `[原文如此]`）。
- 原文为英文则保留英文；解析者的说明用中文，且说明与摘录分行书写，说明行以 `说明：` 开头。
- 禁止对原文做概括后冒充摘录；概括必须明确写 `概述：`。

## 3. 表格输出

- 表体用 Markdown 表格；表头多层时第一层写在表上方 `表头层级1：…`。
- 合并单元格：被合并位置写 `↑（同上行）` 或 `←（同左列）`，并在表下注合并范围。
- 表格超过 20 列时改用"单元格清单"格式：`r2c3 = 0.87`。

## 4. 公式输出

- 单独成行，前缀公式编号：`式(3) [p.7] [conf:medium]`。
- 希腊字母用 Unicode 原字符（α、β、γ、Δ、λ、μ、σ、ω）；上下标用 `^` / `_` 线性化；无法线性化时保留原行字符并说明。
- 不解释公式的科学含义（题面要求：按结构元素识别）。

## 5. 文档级结构

主产物 parsed_document.md 固定章节顺序：
1. 解析概览（文件、页数、路线、异常分级摘要）
2. 元数据
3. 章节树
4. 正文（按区块）
5. 图表与题注（含正文引用回链表）
6. 公式对照
7. 参考文献
8. 脚注与页眉页脚处置
9. 置信度与未决事项汇总

## 6. 语言与杂项

- 说明性文字一律简体中文，术语与 references/../templates 中保持一致。
- 文件路径一律正斜杠（`/app/output/...`）。
- 文件编码 UTF-8；脚本读取用 utf-8-sig。
- 所有"判断"都要可复核：凡写"疑似/可能"之处必须给出观察依据（如"≥3 页首行重复"）。
