# GB/T 7714—2015 各文献类型字段模板（兼顾 APA 7 / Vancouver）

目标规范一律以 task.md / case.json 为准；未指明时用本文件（顺序编码制）。
每条模板给出：格式 → 必保字段 → 合成示例（人名刊名均为虚构，仅示意格式）。

## 1. 期刊论文 [J]

```
主要责任者. 题名[J]. 刊名, 年, 卷(期): 起页-止页. DOI.
```
- 必保：作者、题名、[J]、刊名、年、卷(期)、起止页、DOI（有则录）。
- 合成示例：`张三, 李四, 王五, 等. 低资源命名实体识别的迁移方法[J]. 计算机学报, 2023, 46(3): 512-528. DOI: 10.11897/xx.2023.0512.`
- 英文示例：`Smith J A, Doe B, Roe K, et al. Synthetic pretraining for low-resource NER[J]. Journal of Synthetic Studies, 2022, 15(2): 100-117.`
- 无卷号：`刊名, 年(期): 页码.`；无页码：标「[缺: 页码]」，不编造。

## 2. 专著 [M]

```
主要责任者. 书名[M]. 版本(第1版不标). 出版地: 出版者, 年: 起页-止页(引文页).
```

## 3. 专著/论文集析出 [M]// / [C]//

```
析出责任者. 析出题名[C]//论文集责任者. 论文集名. 出版地: 出版者, 年: 起页-止页.
```
- 会议论文 BibTeX inproceedings → 此型；会议名不全时标「[缺: 会议名]」。

## 4. 学位论文 [D]

```
责任者. 题名[D]. 城市: 培养单位, 年.
```

## 5. 报告 [R] / 标准 [S] / 专利 [P] / 报纸 [N]

```
[R] 责任者. 报告名[R]. 出版地: 出版者, 年.
[S] 标准编号 标准名称[S]. 出版地: 出版者, 年.
[P] 专利申请者. 专利名: 专利号[P]. 公告日期.
[N] 责任者. 题名[N]. 报纸名, 年-月-日(版次).
```

## 6. 电子资源 [EB/OL]

```
责任者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```
- `[引用日期]` 必填真实访问日期；不知道该日期就标「[缺: 引用日期]」，不编造。

## 7. 著录通则

- **作者**：3 名以上列前 3 名，中文加「, 等」，英文加「, et al.」；欧美作者姓全称
  在前、名缩写不加点多字连写（Smith J A）；中文拼音姓全拼（ZHANG San 或 Zhang S，
  全表统一）。
- **标点**：GB/T 7714 著录项目之间用半角 `.` `,` `:` `//`；中文条目同样用半角。
- **多次引用同一文献**：正文同号，需引具体页用「[1]25-26」上标页码。
- **预印本**：`[EB/OL]` 或按目标规范；有正式版后改为正式版并注明预印信息。

## 8. APA 7th 对照（任务指定 APA 时用）

```
Author, A. A., & Author, B. B. (Year). Title of article: Sentence case. Journal Name in Title Case Italics, Volume(Issue), pp–pp. https://doi.org/xxxx
```
- 差异要点：作者最多列 20 名；题名句首大写；刊名与卷斜体；DOI 用 https://doi.org/
  前缀；无「[J]」类型标识。

## 9. Vancouver 对照（任务指定时用）

```
Author AA, Author BB. Title of article. Journal Abbrev. Year;Volume(Issue):pp-pp.
```
- 差异要点：作者≤6 名，超出加 et al.；刊名用 ISO 4 缩写；年;卷(期):页 紧凑格式。

## 10. 缺失字段标注约定（诚实红线）

| 情形 | 标注 | 禁止 |
|---|---|---|
| 缺页码 | 条目末加「[缺: 页码]」 | 推测页码区间 |
| 缺年份 | 「[缺: 年份]」 | 用相近文献年份顶替 |
| 缺卷/期 | 「[缺: 卷期]」 | 编造卷期号 |
| 缺 DOI | 不标（非必填），有但形态可疑标「[待核验: DOI]」 | 拼凑 DOI |
| 缺刊名/出版社 | 「[缺: 刊名]」/「[缺: 出版者]」 | 用文献库简称冒充全称 |
