# 要素齐全性清单与评分锚点（参考文献与引用管理）

交付前逐项勾选。每条标注对应的评分维度（题面 §2），未勾项必须在 result.json 的
uncertainty 或待确认清单中说明原因。

## A. 契约与交付（任务完成度 15 分）

- [ ] A1 已读 /input/case.json，result.json 含 `case_id` 且与 case.json 一致
- [ ] A2 `output_contract` 声明的全部原始字段已透传（字段名一字不差）
- [ ] A3 status 诚实（success/partial/failed），sources / uncertainty / change_log 齐全
- [ ] A4 主产物可继续编辑（md/docx/tex），非只读图片
- [ ] A5 先落盘过至少一份 partial，再迭代（change_log 可见演进）
- [ ] A6 文献库快照保存在 /app/work（可回溯到原始输入）

## B. 挂得对——引用插入与定位（结果正确性 15 分）

- [ ] B1 每个引用标记落在被支撑论断所在句（句末或句中），非整段末尾一串
- [ ] B2 需要支撑的句型已逐类排查：事实断言、数据/数值、方法来源、定义、对比结论
- [ ] B3 一句多引合并标注（[1-3] 或 [1,3]），未拆成连续多个孤立标记
- [ ] B4 多句一引时引用挂在首次出现的论断句
- [ ] B5 本文贡献句、常识句、推导句未误挂引用

## C. 编得顺——编号更新与交叉引用（结果正确性 / 可靠体验）

- [ ] C1 文献表编号为 1..N 连续无断号（citation_check.py 验证）
- [ ] C2 编号顺序 == 正文首次出现顺序（顺序编码制）
- [ ] C3 插入/删除/调序后正文标记、文末列表、图表注、附录引用已同步
- [ ] C4 引用样式全稿统一（同为上标或同为方括号；著者-出版年制年份格式一致）

## D. 收得净——去重与归并（结果正确性 / 创新增益）

- [ ] D1 dedupe_refs.py 全部候选对有明确决策：合并或保留，判据记录在案
- [ ] D2 中英文题名重复、预印本 vs 正式版、数据库重复导出已排查
- [ ] D3 合并保留元数据更全/正式出版的版本，正文引用统一指向保留条
- [ ] D4 无反并错误：同第一作者同年的不同文献未被误并（判据见 method_rules §4）

## E. 对得上——来源核验与一致性（结果正确性 15 分 / 可核验性 5 分）

- [ ] E1 每条条目可定位回文献库快照原始记录（evidence_map 有 S# 对应）
- [ ] E2 DOI 形态、年份合理性、卷期页逻辑已机检；存疑条目标「[待核验]」
- [ ] E3 正文论断与所引文献主题/结论逐句比对；不匹配的标「[引证存疑]」
- [ ] E4 citation_check.py 报告无 ERROR；WARN 均已处理或列入待确认
