# 要素齐全性清单与评分锚点（阅读14：Nanopublication）

用法：交付前逐条勾选。锚点格式 `[S# p.页 §节/fig.图/表N]`；nanopub 结构名词见
SKILL.md 与 templates/nanopub_template.trig。

## A. 拆得细（断言粒度）

- [ ] A1 每条断言只含一个可判真假的命题（一个主语、一个关系、一个客体集合）。
- [ ] A2 复合句（并列、因果、对比）已拆成多条断言，因果链各环单独成条。
- [ ] A3 每条断言带条件限定（体系、温度、浓度、数据集、样本量等），或显式说明
      "该断言为定义/无条件断言"。
- [ ] A4 没有"整段摘要塞进一个断言"的现象；断言总数与论文结论密度相称
      （一篇实验论文通常 5-20 条，只有 1-2 条要自查是否漏拆）。

## B. 对得上（证据绑定）

- [ ] B1 每条断言挂最小充分证据片段：原文引文 ≤30 字 + 锚点，多一字不引。
- [ ] B2 证据类型逐条标注：直接（数据/图表直接给出）/ 间接（多处信息推论）/
      作者声明（无数据支撑的观点句）。
- [ ] B3 锚点编号 S# 在 materials_register.md 中登记，且含定位（页/节/图表）。
- [ ] B4 证据跨图表的断言并列记录全部锚点，断言文本注明"综合图N与表M"。
- [ ] B5 找不到支撑片段的断言标"证据不足"+ low 置信度或移出，未硬挂无关证据。

## C. 追得回（来源元数据）

- [ ] C1 每条 nanopub 的 provenance 含 prov:wasDerivedFrom，指向材料内找到的
      真实标识符（DOI/URL）；缺则记"未报告"，无编造。
- [ ] C2 pubInfo 含创建者（ORCID 或"未报告"）、创建时间（xsd:date）、许可。
- [ ] C3 论文标题/作者/年份/版本在 assertion_table.md 头部登记，与原文一致。
- [ ] C4 同一断言去重：同一论文相同命题只发一条 nanopub，合并处记录合并依据。

## D. 读得懂（导出可用性）

- [ ] D1 nanopub_check.py 全部通过：词法完整、括号配平、前缀闭合、句点结尾、
      四图齐全、assertion 图非空。
- [ ] D2 前缀只增不改：同一前缀全文件指向同一 IRI；未声明前缀零使用。
- [ ] D3 命名图标签本地名固定为 Head/assertion/provenance/pubInfo。
- [ ] D4 关系类型取自 references/method_rules.md 的映射约定或领域本体，
      同一语义不用两种拼写。
- [ ] D5 不确定断言带置信度（high/medium/low）+ 一句依据。

## E. 契约与诚实（result.json）

- [ ] E1 result.json 含 case_id，与 case.json 一致。
- [ ] E2 output_contract 全部原始字段透传，字段名逐字一致。
- [ ] E3 status 诚实：有缺口即 partial，uncertainty 逐条说明。
- [ ] E4 sources 列出实际使用的 S 编号；change_log 记录每轮改动（含脚本降级）。
