# rubric-checklist — "编译得通/改得对/交得可用/复现得了"自查 + 5 评分维度对照

版本 1.0.0。题面四问逐项落到 Skill 内的检查动作；提交前逐条打勾。

## 1. 四个核心问题 → 落点与自查

### 1.1 编译得通
- 落点：build_loop.py 轮次协议 + 收敛判定（exit=0 + aux 标签哈希稳定 + 无 rerun 警告）。
- 自查：result.build.converged 与 build_report 一致；报错定位到 file/line/根因
  （parse_log 全量，不止第一条）。

### 1.2 改得对
- 落点：error-playbook 修复知识表 + source_changes 记录。
- 自查：每处改动有类别依据；公式符号/编号、表格数值与列宽、交叉引用/参考文献、
  模板必填项的修改都对应到具体 error_table 条目。

### 1.3 交得可用
- 落点：$OUT 下 PDF + 可继续编辑的源码 + result.error_table。
- 自查：交付的是结构清楚、可维护的源码与真实产物；不是 PDF 截图或不可编译片段；
  未完成部分如实 partial。

### 1.4 复现得了
- 落点：repro_record.py（引擎版本/宏包/字体/命令序列/轮次/输入哈希/收敛状态）。
- 自查：他人按 repro_record 能重建同一产物；降级路径时明确"未实际编译"。

## 2. 5 评分维度对应物

| 维度 | 本 Skill 对应物 |
|---|---|
| 实际效果 40 | 真实编译产物/错误定位表；收敛判定硬标准；行号级定位 |
| 使用增益 25 | 轮次协议自动化（不再手动跑 4 遍）；全量错误表（不再一条条试）；修复知识表 |
| 创新增益 15 | 收敛判定（aux 哈希）+ 错误根因分类（13+9 类）+ 静态降级路径（无 TeX 环境仍可体检）；边界如实声明 |
| 可靠体验 10 | 固定脚本链；退出码 0/1/3 语义明确；超预算/无环境都有如实分支 |
| 生态贡献 10 | USAGE/error-playbook 完整可复用；selftest 内置样例 log；源码改动可审计（source_changes） |
